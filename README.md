# objects_exercise

objects_exercise is a small practice project created as part of my bootcamp to learn and understand how to work with objects in JavaScript.

## Features

* Create objects – Define and initialize JavaScript objects
* Access properties – Read values from object properties
* Modify properties – Update existing object values
* Add properties – Extend objects with new properties
* Object methods – Work with functions inside objects
* Nested objects – Practice working with objects inside other objects

## Technologies

* HTML
* CSS
* JavaScript
